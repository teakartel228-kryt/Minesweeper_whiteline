# MINESWEEPER: WHITELINE

Сапёр с градусником вместо права на ошибку. Вся игра лежит в одном файле `index.html`, без сборки и зависимостей.

**Играть онлайн:** `https://<твой-ник>.github.io/<название-репозитория>/`

## Как это работает

- Каждое открытие клетки, флаг или аккорд нагревает градусник. Он остывает сам. Заполнился, значит проиграл.
- Когда нагрев впервые заходит в новую полоску, ты получаешь 🛡 парирование (оно спасает от одной мины), а на поле добавляется мина.
- В конце поля ставится оценка от F до S, а P означает идеальное прохождение. Подсказка 💡 открывает безопасную клетку, но снижает оценку.
- Режимы: KAIZO, УльтраКАИЗО, Чайник, Дзен, На время, Песочница, нестандартные карты, Рогалик, Дуэль и «КРУГ НОМЕР ТРИ?!».
- Подробные правила есть в игре, кнопка «Как играть».

## Запуск локально

Достаточно открыть `index.html` в браузере. Или так:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Публикация на GitHub Pages

1. Положи `index.html` в корень репозитория, ветка `main`.
2. В репозитории открой **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. После пуша workflow `.github/workflows/pages.yml` сам выложит сайт. Его можно запустить и вручную, вкладка **Actions**.

## Сторонние компоненты

- Встроенный эмулятор Game Boy использует [WasmBoy](https://github.com/torch2424/wasmboy) 0.7.1 (автор Aaron Turner, GPL-3.0-or-later). Он подгружается с CDN (jsDelivr или unpkg), поэтому для этой функции нужен интернет.
- Шрифт Roboto Flex подгружается с Google Fonts.
- ROM-файлы не распространяются. Их нужно загружать самостоятельно и только те, на которые у тебя есть права. Проект никак не связан с Nintendo.
