# Contributing

The whole game is a single file: `index.html` (HTML + CSS + JS, no build step).

1. Fork and clone the repo.
2. Open `index.html` in a browser (or run `python3 -m http.server` and open `localhost:8000`).
3. Make your change, test on desktop and on a phone-sized viewport.
4. Open a pull request with a short description and, if the UI changed, a screenshot.

Please do **not** add copyrighted images, audio or ROM files. Only content you made yourself or that has a compatible license.

By contributing you agree that your work is released under GPL-3.0-or-later.
